# Case

`case_top.stl` and `case_bottom.stl` are the printed enclosure from
**[zimengxiong/tinytouch](https://github.com/zimengxiong/tinytouch)**, redistributed here
unmodified under its MIT licence (see `LICENSE.tinytouch`). This project uses the same
board and sensor as tinytouch, so the same case fits without changes.

Copyright (c) 2026 Zimeng Xiong.

## Printing

No supports needed for either half in the orientation they are saved in. Standard PLA at
0.2 mm works; the sensor bezel is the only tight tolerance, so print a top half first if
you are dialling in a new filament.

Route the sensor's five wires before closing the halves — the ZW101 pigtail is short and
awkward to seat afterwards.
